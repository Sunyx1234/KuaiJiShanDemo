# 会稽山数字孪生运营中心

基于 Vue 3、TypeScript、Vite、Element Plus、ECharts、Pinia 与 Vue Router 4 开发的 1920 × 1080 数字孪生可视化大屏。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端输出的本地地址。

园区大屏：访问 `/#/park/huijishan`，地球主页为 `/#/`。总览、安监和访客视图的中央场景默认展示会稽山园区 v1.0 三维模型，可切换到园区航拍图。旧地址 `/#/park/jiaxing` 自动跳转到新地址。独立三维测试页为 `/#/huijishan-model`，支持拖动旋转、滚轮缩放、右键平移及视角复位。原演示点位按模型范围近似映射，真实业务区域仍需用园区坐标重新标定。模型源文件是 `会稽山园区_照片复原_v1.blend`，可用 `scripts/export_huijishan_glb.py` 重新导出。地球主页和周边卡片中的业务数值目前是演示数据，正式口径待确认。

原嘉兴园区概念模型的独立预览保留在 `/#/park-model`，仅供对比早期方案。
支持拖动旋转、滚轮或双指缩放、自动旋转、俯视和复位；键盘方向键旋转，`+` / `-` 缩放，`Home` 复位。
此旧预览根据单张参考图构建近似建筑模型，未用于会稽山园区大屏。
建筑布局参数位于 `src/three/parkLayout.ts`，几何与材质位于 `src/three/createJiaxingPark.ts`。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist` 目录。

## 主要交互

- 顶部一级导航切换业务指标。
- 风险分布、告警分类和能耗类型/日月年维度筛选。
- 场景图层控制、点位定位和设备详情查看。
- 监控画面放大、告警详情弹窗、全屏切换。
- 1920 × 1080 基准画布整体等比例适配，兼容非 16:9 屏幕。

模拟数据集中维护在 `src/data`，后续可直接替换为接口数据。
