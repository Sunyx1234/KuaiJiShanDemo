# 会稽山数字孪生运营中心

基于 Vue 3、TypeScript、Vite、Element Plus、ECharts、Pinia 与 Vue Router 4 开发的 1920 × 1080 数字孪生可视化大屏。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端输出的本地地址。

园区大屏：访问 `/#/park/huijishan`，销售流向地球主页为 `/#/`，使用业主提供的 10 笔 CRM 订单展示绍兴、合肥、嘉兴、马鞍山和苏州 5 个地市的流向，每 8 秒轮播，卡片与连线同步淡入淡出，支持暂停、选单和前后切换。右侧展示2026年上半年公司经营、产品与区域销售指标，订单详情在地球上的悬浮卡片展示。订单快照位于 `src/data/crmOrderSnapshot.json`，标准化和数量单位处理位于 `src/data/sales.ts`。企业总览、生产工艺、设备运维和安全监控四个主题的中央场景默认展示会稽山园区 v8 三维模型，可切换到园区航拍图。旧地址 `/#/park/jiaxing` 自动跳转到新地址。独立三维测试页为 `/#/huijishan-model`，支持拖动旋转、滚轮缩放、右键平移及视角复位。原演示点位按模型范围近似映射，真实业务区域仍需用园区坐标重新标定。模型源文件是 `会稽山园区_照片复原_v1.blend`，可用 `scripts/export_huijishan_glb.py` 重新导出。公司经营数据集中在 `src/data/businessReport.ts`，包含半年报和经营数据公告来源。

原嘉兴园区概念模型的独立预览保留在 `/#/park-model`，仅供对比早期方案。
支持拖动旋转、滚轮或双指缩放、自动旋转、俯视和复位；键盘方向键旋转，`+` / `-` 缩放，`Home` 复位。
此旧预览根据单张参考图构建近似建筑模型，未用于会稽山园区大屏。
建筑布局参数位于 `src/three/parkLayout.ts`，几何与材质位于 `src/three/createJiaxingPark.ts`。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist` 目录。

## 主要交互

- 园区顶部导航：企业总览、生产工艺、质量追溯、设备运维、订单履约。
- 企业总览采用独立布局：中央模型上方四项等宽经营指标，订单金额分布、产品金额结构、区域客户分布，中央四类厂区高亮，右侧生产摘要，以及底部订单、发货、签收和异常动态。支持近7日 / 本月切换和指标、图表下钻，明细可打开共用订单生命周期。
- 企业总览按订单创建时间、出库时间和签收时间分别统计；经销商按客户编码、签收运单按运单编码去重。月度页面按用户确认汇总整个10笔订单快照；近7日按展示时间过滤。数量按箱、坛及包装件分别统计，商品与单据均支持一对多关联。
- 选择生产批次、检验任务或设备，联动档案、参数、业务记录与园区点位。
- 三个主题通过批次和设备关联，跨主题跳转保留所选记录，模型与镜头连续。
- 底部展示工艺链、追溯链、维护流程和履约链。生产页可点击六个工艺环节，联动中央模型厂房表面着色；查看环节与批次实际进度独立。
- 订单生命周期详情在园区与地球共用，包含商品、数量、关联单据和节点时间轴。
- 设备页可切换园区定位与设备视图。独立GLB资产在 `src/data/processRegions.ts` 的 `equipmentModelCatalog` 登记，尚无资产时展示准备状态。
- 园区大屏已移除安监、访客模块入口与安监工单轮询。历史独立工单页面及服务代码保留。
- 1920 × 1080 基准画布整体等比例适配，兼容非 16:9 屏幕。

园区展示数据集中在 `src/data/factory.ts`，订单生命周期在 `src/data/fulfillment.ts`，工艺区域映射在 `src/data/processRegions.ts`，选中记录与主题关联位于 `src/stores/factory.ts`。当前数据用于确认展示结构，并未对接 MES、LIMS 或设备采集平台；工艺步骤、质量结果与标准、设备位置和指标口径需客户确认。展示功能本身不作为未来工厂评分项已达标的证据。

企业总览统计与厂区映射位于 `src/data/enterpriseOverview.ts`，周期、厂区选择和下钻筛选位于 `src/stores/enterpriseOverview.ts`。经营指标、分析图表、生产摘要、业务动态各用独立组件，后续主题页可以分别设计。

## CRM订单展示口径（2026-10-15）

- 来源为业主提供的 `CRM订单链路_全链路完整10条_20261014.xlsx`，快照包含10笔订单、30行商品、12张要货单、34张发货通知及29张ERP出库单。
- 按用户要求，页面支付金额统一等于订单金额；月度统计纳入全部10笔。
- 订单各环节时间按用户确认的展示排期统一维护于 `src/data/orderTimeline.ts`：下单日期分散至8月初至10月上旬，履约周期约5–10天，备货与运输间隔各不相同；地球卡片、订单详情、签收记录和业务动态共用这一排期，原始快照与业务单据编号保留。配送送达和签收记录按用户授权补齐为12笔闭环运单；页面不增加模拟说明。运输数量保留源出库数量，拆分运单的签收数量与本次出库数量保持一致。
- 单位编码保留在商品 `unitCode` 中；展示按商品名称与规格还原箱装、坛装和包装物。包装物不混加为箱数，原订单数量、原出库数量均留存在快照内。
- 工艺和设备主题仍为独立展示场景；CRM订单不再套用虚构生产批次或设备关联。

- 园区导航保留企业总览、生产工艺、设备运维和安全监控；已移除质量追溯与订单履约独立页面。原安监的监控点位、视频预览、AI告警与工单台账恢复，订单详情仍可从地球页和企业总览访问。
