# 正泰集团厂区综合态势运营中心 · 售前演示故事线与演示脚本

> 版本：1.0（售前演示用）
> 适用对象：企业决策层（董事长/总裁级）
> 演示时长：完整版 5–8 分钟，精简版 3 分钟
> 配套素材：当前 demo（集团地球 → 园区下钻 → 三专题切换 → 工单闭环 → 移动端）

---

## 0. 文档说明与核心原则

这份文档分三部分：

1. **故事线思路**——为什么这么讲（给演示者自己看的底层逻辑）
2. **演示脚本**——怎么讲（逐字稿 + 操作 + 停顿，拿来就能排练）
3. **决策点清单**——讲完怎么收口逼表态（附在最后）

**一句话核心原则：老板买的不是「大屏」，是三种东西——掌控感、安全感、面子（标杆效应）。**

> 演示全程反复自检：我现在这句话，是在讲「功能」，还是在讲「老板的焦虑被解决」？前者是浪费，后者才有效。

# 第一部分 · 故事线思路

## 1.1 老板到底为什么买它（不是为什么买「大屏」）

对正泰这种跨国制造集团的老板来说，功能是「无感」的，焦虑才是真实的。整个故事线围绕他的三个焦虑展开：

| 老板的真实焦虑 | 一句话翻译 | demo 对应物 |
|---|---|---|
| **管不到** | 30+ 基地、140+ 国家，靠人跑不过来，靠报表是滞后的 | 三维地球 + 全球一盘棋 |
| **看不透** | 各基地数据在各自系统里，割裂、口径不一 | 园区下钻 + 数据穿透 |
| **防不住** | 一次安全事故毁掉市值和声誉；产线停摆损失按分钟算 | AI 安监 + 工单闭环 |

**这三句话就是整个演示的骨架。** 任何模块的介绍，都要「挂靠」到其中一句上，否则就是散装功能。

## 1.2 故事线：一条「从宏观穿透到微观」的主线

```
全球（我够得到多少）
  ↓ 下钻
基地/园区（我看得透不透）
  ↓ 下钻
车间/设备/告警（我防不防得住）
  ↓ 闭环
处置完成、可追溯（我能不能兜底 + 留痕）
```

这条线的价值在于：它模拟了老板**日常管理时的心智动作**——先看大盘，发现问题，钻下去，处置掉。老板会在演示过程中不自觉地「代入自己坐在那个指挥中心里」。

## 1.3 五幕结构总览

| 幕 | 内容 | 对应焦虑 | 时长 | 关键动作 |
|---|---|---|---|---|
| 开场 | 定调：把「30 基地装进一个屏」 | 全部 | 30s | 只讲问题，不讲功能 |
| 第一幕 | 全球层 | 管得到 | 1min | 转地球 + 点击下钻 |
| 第二幕 | 下钻穿透 | 看得透 | 1.5min | 点到具体设备/告警 |
| 第三幕 | 安全 + 工单闭环 | 防得住 | 1.5min | 告警→派单→处置→归档 |
| 第四幕 | 访客（真实数据） | 可信度 | 1min | 强调「已接真实 API」 |
| 收口 | 逼表态 | 决策 | 30s | 抛「先试点哪个」 |

## 1.4 价值翻译表：把「系统指标」翻译成「老板语言」

现在 demo 上的指标是「系统健康度」，老板不关心。演示时要么改文案，要么**口头补一句翻译**：

| demo 现指标（系统语言） | 老板真正关心的（演示时怎么说） |
|---|---|
| 摄像头在线率 97.9% | 「您的安防网是『活着』的，不是摆设」 |
| 定位在线率 97.7% | 「每个访客在哪，是实时的，不是事后查」 |
| 今日告警数 23 条 | 「今天有 23 个风险点，**每一个都能被追到闭环**」 |
| 全球制造基地 30+ | 「您的手够不到的地方，屏幕替您够到」 |
| 能源模块（空白） | 抛决策钩子：「这块您最想先看什么？」 |

> 原则：**每个指标后面，必须跟一句「这对老板意味着什么」。** 只说数字 = 念说明书。

## 1.5 正泰特有的「双价值点」（这是别人没有的加分项，务必讲）

正泰自己就是「卖智慧能源、智能配电、数字工厂解决方案」的公司。所以这个大屏对正泰是**双重价值**：

1. **对内**：全球基地管控中枢（前面讲的那些）。
2. **对外**：**它是「正泰数字化水平」的活广告。** 客户、政府领导来参观时，这块屏就是「正泰自己就在用智能制造」的最强说服力。

> 演示中轻描淡写补一句，分量极重：
> 「这套大屏对内是您的全球管控中枢，对外也是正泰『智能制造标杆』的展示窗口——客户来看，看到的不只是产品，是正泰自己就在用这套数字化能力。」

# 第二部分 · 演示脚本（逐字稿 + 操作）

> 说明：
> - `【话术】` = 直接念的台词
> - `【操作】` = 演示者手上做的动作
> - `【停顿/提问】` = 停下来等老板表态的决策点
> - 文中「董事长」可根据实际称呼替换（南董/X总）

## 2.0 演示前准备

1. **只准备一台能全屏的大屏/投影**，1920×1080，别用笔记本小屏——大屏的冲击力是这个 demo 的一半价值。
2. **提前把「真实/演示/示意」三态标注做上屏**（见文末落地清单），这是信任锚。
3. **删掉演示机上的无关弹窗、通知、浏览器标签**，只留 demo 一个全屏窗口。
4. **排练三遍**，重点练「点击下钻」和「告警处置」两个动作，别在老板面前找鼠标。
5. **备一份 3 分钟精简版**（见 2.7），万一老板时间紧。

---

## 2.1 开场（30 秒 · 定调，不碰功能）

【操作】站着，先不碰屏幕，等全场安静。

【话术】

> 董事长，您在全球有 30 多个制造基地，覆盖 140 多个国家和地区。您今天坐在这里，心里最想问的一个问题，其实是——
>
> **我的全球工厂，此刻到底正在发生什么？**
>
> 靠人汇报，您看到的是昨天的数据；靠报表，您看到的是割裂的数据。
>
> 今天这套系统，就做一件事：把 30 多个基地、上千个关键点位，装进您面前这一个屏幕。把「滞后」变成「实时」，把「割裂」变成「一盘棋」。

【操作】此时才点亮/切入大屏首页（集团地球层）。

---

## 2.2 第一幕 · 全球层（1 分钟 · 讲「管得到」）

【操作】让地球轻轻自转，手指指向发光点。

【话术】

> 这是您的全球制造版图。每一个发光点，是一个制造基地；颜色代表它的接入状态。
>
> 绿色的，是已经接入、数据实时上来的；蓝色的，是正在建设数字模型的；灰色的，是规划中的。
>
> **哪个基地健康、哪个基地还在建设、哪个基地还没接进来——您一眼就知道。**
>
> 董事长，这本质上不是一张地图，这是您的**管理半径**。您的手够不到的地方，屏幕替您够到。

【操作】点击「嘉兴基地」发光点，触发聚焦 + 下钻过渡动画。

【话术】（过渡时）

> 现在我们从「全球」，钻到一个具体的基地去。

---

## 2.3 第二幕 · 下钻穿透（1.5 分钟 · 讲「看得透」）

【操作】进入嘉兴园区层，切换到「综合态势」。

【话术】

> 这是嘉兴基地的实时态势。您看，一个告警点，我能一路钻下去——钻到它具体是哪一栋车间、哪一台设备、现在什么状态。

【操作】点击一个设备标签，打开设备详情面板。

【话术】

> 这台设备，编号、实时功率、近 24 小时运行趋势、最近的告警记录，都在这里。
>
> 董事长，老板最缺的从来不是「更多数据」，而是**「穿透」的能力**——从宏观一眼钻到微观的那台设备。
>
> 报表给不了您这个，因为它到「这个月产能多少」就停了。这套系统能让您钻到「此刻哪台设备正在报警」。

【停顿/提问 · 决策点 1】

> 我先在这里停一下，请您帮我把个方向——
>
> **这个「穿透」的深度，您觉得是要钻到「车间/区域」就够了，还是真的要钻到「每一台设备」？**
>
> 这决定了我们后面数据接入的深度和成本。

> （用意：让老板第一次参与，而不是被动听。无论他答哪个，你们都获得了信息。）

---

## 2.4 第三幕 · 安全 + 工单闭环（1.5 分钟 · 讲「防得住」）

【操作】切换到「安全监控」专题。

【话术】

> 制造业的红线是安全。接下来这段，我给您看一条完整链路——
>
> AI 识别到危险作业 → 产生告警 → 派单 → 现场处置 → 复核归档。

【操作】点击一个「严重告警」，打开告警详情，演示「确认 → 派单」动作。

【话术】

> 您看到的，不只是「AI 能识别危险」——那个很多厂家都能做。
>
> 真正值钱的是后面这半段：**识别之后，能不能闭环。**
>
> 告警产生，谁来处理、处理到哪一步了、有没有超时、最后归档留痕——**出事之后，能追溯「谁在什么时候做了什么」**。这才是把「被动响应」变成「主动预防」。

【停顿/提问 · 决策点 2（重要，主动标注边界）】

> 这里我要向您坦白一句——
>
> 刚才这条处置链路，目前是**演示**，真实生产环境里，AI 识别和处置通常由专业的安监/安防平台来做，我们大屏负责「对接」和「展示」，不抢它的活。
>
> 所以这里想请您定一个方向：**安监这块，您这边是倾向「我们一并做掉」，还是「将来和专业的安监平台对接」？** 这决定这个模块的边界划在哪。

> （用意：这是全片最关键的一次「边界标注」，既显专业，又逼出「安监系统是否立项」这个被搁置的决策。）

---

## 2.5 第四幕 · 访客（1 分钟 · 讲「真实的落地证据」）

【操作】切换到「访客管理」专题，展示访客实时位置 + 轨迹。

【话术】

> 前面很多是演示数据，但接下来这一块，性质不一样——
>
> **访客定位，是接了你们真实访客系统的 API。** 这些在厂人数、实时位置、移动轨迹，是真实系统里流过来的。
>
> 这意味着我们不是只画了一个界面，我们是**真的把你们的系统打通了**。

【停顿/提问 · 决策点 3】

> 这块数据形态，您看看是不是和你们访客系统的实际口径对得上？如果这里没跑偏，说明我们整套「数据接入」的路子是通的，后面其他系统都能照这个模式接进来。

> （用意：这是全片最重要的「信用时刻」。一个真实数据点，胜过十个炫酷动画。）

---

## 2.6 收口（30 秒 · 逼表态）

【操作】回到集团地球层，停下动作，面向老板。

【话术】

> 董事长，我最后不绕弯子。这套系统能不能帮到您，您心里可能已经有判断了。
>
> 我只问您一个具体的问题——
>
> **如果这件事只能先在一个地方落地试点，您希望是哪一个基地、哪一个场景先开始？**
>
> 是先把「全球一盘棋」跑起来，还是先在某一个基地把「安全 + 访客」这两个真实场景做深、做出样板？

【操作】不再说话，等老板回答。

> （收口的关键：**不问「您觉得怎么样」（开放式、容易客套），问「先试点哪个」（封闭式、逼出下一步）**。老板一回答，就从「要不要做」推进到了「从哪开始做」。）

---

## 2.7 精简版（3 分钟电梯版）

万一老板时间紧，只讲这条线：

1. **一句话**（30s）：把全球 30 基地装进一个屏幕，把滞后变实时、把割裂变一盘棋。
2. **一个动作**（1.5min）：点嘉兴 → 钻到某台设备 → 看到一个告警 → 演示处置闭环。
3. **一个真话**（30s）：访客是真实 API 接入，证明数据路是通的。
4. **一个收口**（30s）：先试点哪个基地、哪个场景？

> 精简版的精髓：**地球转一圈就停，剩下全用来「钻下去 + 处置掉」，最后一句逼表态。**

# 第三部分 · 决策点清单（演示完直接用它收口）

演示结束后，把下面这张表拿在手里，逐个和老板确认。**它的目的是把「模糊需求」逼成「明确的下一步」**，而不是当场谈价格。

| 决策点 | 要问的问题 | 老板的回答导向什么 |
|---|---|---|
| 试点范围 | 先落地哪个基地、哪个场景？ | 确定 MVP 边界 |
| 穿透深度 | 钻到车间/区域，还是钻到每台设备？ | 数据接入成本 |
| 安监边界 | 大屏一并做，还是对接专业安监平台？ | 是否催生安监立项 |
| 能源口径 | 能源没建，这块屏先看什么？ | 能源模块的取舍 |
| 真实数据源 | 哪些系统有 API、哪些只有库、哪些要人工？ | 集成方式与工期 |
| 对外门面 | 是否要作为客户参观的展示窗口？ | 是否加「参观模式/一键美化」 |

# 第四部分 · demo 改进落地清单（动手前的 5 件事）

按「杠杆从高到低」，演示前建议改这 5 点：

1. **三态标注（最高优先）**：给每个数据模块标「真实 / 演示 / 示意」。访客标「真实」，其他标「演示」，能源标「示意」。这是信任锚，主动示弱反而加分。
2. **指标翻译**：把几个关键指标的文案，从系统语言改成老板语言（见 1.4 表），至少演示时口头补一句「这意味着什么」。
3. **砍技术炫技**：地球自转、粒子、辉光演示一遍就够，重心移到「点进去 → 钻下去 → 处置掉」三个动作。
4. **能源模块给「决策钩子」**：别让它空白着，放一句「能源系统待接入 · 您最想先看哪类数据？」把缺口变成让老板参与的入口。
5. **备 3 分钟版**：老板时间永远比你想的少。
