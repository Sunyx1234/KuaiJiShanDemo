# 酒瓶产线 · 六机静态装配 v0.2

顺序：上料机 → 酒瓶质检机 → 环形灌装机 → 高温杀菌机 → 旋盖机 → 装箱机。按用户指定顺序建立空间布局；未对生产工艺进行校核。所有单机均为现有 Blender 文件的副本，源文件保持不变，单位为米，主物流朝世界 +X。

## 当前文件

- `model/酒瓶产线_六机联线.blend`：当前六机可编辑产线，设备与机构独立分组。
- `model/bottling-line.glb`：当前六机静态导出，不含摄影棚、动画和线框占位盒。
- `model/asset-manifest.json`：装配变换、世界接口和连接段参数。
- `model/verification.json`：六个单机 model 目录 SHA-256、五段连接误差及静态状态检查。
- `model/reload-verification.json`：重新读取源模型与 GLB 后的接口、设备数量和导出检查。
- `renders/01_line_overview.png`：六机透视总览。
- `renders/02_line_top.png`、`03_line_front.png`：六机平面及正面布置。
- `renders/04_transfer_detail.png`：灌装、杀菌及后段衔接。
- `renders/05_downstream_detail.png`：旋盖至装箱段。

旧三机源文件 `model/酒瓶产线_上料-质检-环形灌装.blend` 保留供对照，当前 GLB、manifest 和渲染对应六机版本。修改前的完整三机交付及脚本备份位于 `versions/before-six-equipment-20261019-080615/`，含文件哈希清单。

## 输送连接

| 连接段 | 长度 m | 输送面高度变化 m | 宽度变化 m |
|---|---:|---|---|
| 上料 → 质检 | 6.0 | 1.55 → 0.95 | 1.49 → 0.28 |
| 质检 → 灌装 | 3.0 | 0.95 → 1.162 | 0.28 → 0.18 |
| 灌装 → 杀菌 | 3.0 | 1.162 → 0.90 | 0.18 → 0.72 |
| 杀菌 → 旋盖 | 2.5 | 0.90 → 1.02 | 0.72 → 0.26 |
| 旋盖 → 装箱 | 3.0 | 1.02 → 0.76 | 0.26 → 0.60 |

各接口采用水平交接，连接段包含带面、回程带、护栏、边梁、调平脚和驱动示意。高度转换在中部斜段完成。

另外在产线中补充杀菌机 12.8 m 机内输送带（源单机仅有预留通道），以及装箱机两端接口到原有机内输送段的约 0.72 m 接驳板。旋盖机、质检机及装箱机已有的内部输送系统直接保留。杀菌带与接驳件归产线独立分组，不写回单机源文件。杀菌机的预留线框体不会导出为实体。

## 方案范围

这是静态排布与连接模型。宽幅汇流、单列与多列转换、坡度和瓶体稳定性尚未按瓶型或产能验证；模型不代表已具备可投产的理瓶控制、工艺节拍或热工设计。未进行全场机械碰撞、运动包络与人员检修空间校核。酒液、蒸汽、冷却水、排水、排气、CIP 和压缩空气接口保留，未铺设公用管网。空箱补给、成箱后的码垛及后续设备不在当前装配范围。

## 重建

在项目根目录以 Blender 后台运行 `scripts/build_line.py`，再运行 `scripts/verify_line.py`。覆盖输出前脚本自动备份 model、renders、scripts 和 README 至带时间戳的 versions 目录。人工修改现有版本前也应先备份。
