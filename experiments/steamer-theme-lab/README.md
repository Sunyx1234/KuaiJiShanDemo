# 蒸饭机主题页实验

入口：启动 `npm run dev`，打开 `http://127.0.0.1:5173/#/experiments/steamer`。

页面源文件：`src/views/SteamerExperimentView.vue`。
使用现有 `experiments/equipment-04-rice-steamer/model/rice-steamer.glb`，由 Vite 导入并在构建时打包。没有更改源模型或替换正式主题页。

## 实验范围

- 工艺模式：温度、进料流量、处理时间，选择参数联动趋势。
- 设备模式：驱动电流、运行时长、驱动转速；触发/清除模拟过流事件，驱动总成材质高亮与近景定位。
- 环境反射、柔光、地面阴影，柔光棚拍/大屏夜景两种呈现（默认大屏夜景）。
- 全景、侧视、俯视，拖动旋转、滚轮缩放，标注显示开关。
- 基于模型接口节点定位进出料，温度位置为示意；驱动定位使用真实模型部件层级。
- 仅在相机、布局或状态变化时渲染，无常驻自动旋转。

## 数据边界

全部数值、阈值、趋势、批次与故障事件为固定模拟数据。没有真实设备连接、实际报警推断、内部机构动画或整条生产线装配。模型尺寸与传感器位置待现场核实。驱动转速与运行时长属于设备读数，不等同于出料接口传感器。

## 检查

- `npm run build`：类型检查与生产打包。
- 浏览器检查：GLB 加载、全景构图、模式切换、模拟故障触发与清除、驱动总成定位、灯光切换、标注开关。

## 大屏风格对齐

复用原有 ScreenFrame 的 1920×1080 等比缩放；采用原大屏深蓝背景、暖金标题、HUD 切角边框、青蓝指标及工艺链。模型改为有限尺寸、有厚度的深色底板，外围透视网格，与园区模型的场景展示方式衔接。原模型材质保持不变，渲染侧采用 AgX 色调映射及冷色灯光。

## 原大屏集成入口

进入园区页面 `/#/park/huijishan`，选择“生产工艺”或“设备运维”，点击底部“02 浸米蒸煮”。两侧沿用原有卡片与当前档案；中间先预加载蒸饭机，再用约 0.65 秒推进至预处理区域楼宇内部，在穿墙阶段交叉淡入设备模型（淡入约 0.3 秒）。支持返回园区、中途取消、连续节点切换及减少动态效果偏好。

目前只接入蒸饭机，其他节点保留园区定位。楼宇定位使用现有工艺区域示意映射，尚未绑定真实楼宇、设备和测点。设备模型不代表两侧当前批次或设备档案的实时数据。

验证：生产构建通过；浏览器核验生产工艺与设备运维入口、设备加载、返回园区和中途取消。更新状态模块后，已打开的旧页面需完整刷新一次。
