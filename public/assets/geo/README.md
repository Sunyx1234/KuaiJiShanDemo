# 地球边界资源接入说明

此目录只接收已经完成来源确认、授权确认和地图合规检查的 GeoJSON。

接入前必须确认：

1. 文件坐标系为 EPSG:4326，经度在前、纬度在后。
2. 中国及省级行政区域资源具有可追溯的标准地图来源和审图号。
3. 授权范围允许在本项目生产环境中公开展示。
4. 文件已经离线抽稀，不能直接使用高精度原始边界拖慢大屏。
5. 在 `src/data/globeBoundaries.ts` 登记资源地址、来源网址、审图号和授权状态。

## 当前演示资源

`world-countries-china-pov.geojson`：

- 来源：Natural Earth 1:10m Admin 0 Countries，China POV
- 版本：5.1.1
- 授权：Public Domain
- 处理：Mapshaper 保留 8% 几何细节，坐标精度 0.02°
- 用途：用于本地及云端演示环境的地球国家边界视觉展示
- 生产状态：应用户当前演示需求进入生产构建，但未取得中国自然资源主管部门审图号，代码中保持 `demoOnly` 标记

正式对外发布前，应使用自然资源部标准地图服务系统的世界地图成果完成复核或替换，并记录审图号。
