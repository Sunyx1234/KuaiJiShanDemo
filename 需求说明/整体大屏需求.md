请根据我项目文件夹中的UI效果图以及素材，开发一套可交互的“正泰集团厂区运营中心”前端大屏。
参考图是本次开发的主要视觉依据。请优先保证页面结构、模块位置、尺寸比例、视觉层级和整体氛围与参考图一致，不要脱离参考图重新设计。
一、开发目标
开发一个能够直接运行、具备完整页面结构和真实交互效果的前端大屏，而不是只生成静态效果图、HTML片段或局部代码。
最终交付内容应包括：
完整、可运行的前端项目；
页面所需组件、样式和模拟数据；
图表及交互功能；
本地启动和构建命令；
所有素材正确引用，不依赖失效的外部链接。
二、技术栈
固定使用以下技术栈，不要替换：
Vue 3；
TypeScript；
Vite；
Element Plus；
ECharts，建议通过 vue-echarts 封装；
Element Plus Icons；
Pinia；
Vue Router 4。
组件使用 Vue 3 Composition API 和 <script setup lang="ts"> 编写。
三、视觉还原要求
还原原则
严格参考上传的UI效果图进行高精度还原，不要擅自改变整体设计语言。
重点还原：
页面整体分区；
顶部标题和导航结构；
左右两侧数据面板；
中央厂区主场景；
顶部核心指标栏；
底部实时监控及事件处置区域；
面板尺寸、边框、间距和对齐关系；
图表类型、数据密度和视觉层级；
信息标签、告警标记和状态颜色；
深色工业科技风格。
如果参考图与文字说明发生冲突，以参考图的视觉结构为优先，文字说明用于补充交互和功能。
基准尺寸
以 1920 × 1080 为基准设计画布；
页面保持 16:9 比例；
基准分辨率下首屏完整展示；
页面不得出现横向或纵向滚动条；
页面缩放时采用整体等比例适配；
不允许出现组件错位、文字重叠、图表裁切、素材变形或内容溢出；
对非16:9屏幕可采用居中显示，并用背景色填充剩余区域。
建议通过统一的大屏缩放容器实现适配，不要让各模块分别进行无规则缩放。
视觉风格
页面整体采用：
深蓝黑色背景；
半透明深蓝数据面板；
HUD科技描边；
细线网格和局部科技纹理；
少量蓝色、青色发光效果；
克制的渐变、阴影和呼吸光效。
状态颜色保持统一：
正常：绿色；
提示：蓝色；
关注：黄色；
告警：橙色；
严重告警：红色。
避免以下效果：
大面积高饱和渐变；
过强霓虹光效；
夸张立体阴影；
频繁闪烁；
大幅弹跳动画；
与参考图不一致的卡片化后台风格。
四、页面结构
页面采用以下整体结构：
顶部导航 + 左侧监测栏 + 中央数字孪生主视图 + 右侧安全运营栏 + 底部监控处置区
页面区域	参考比例	主要内容
顶部导航区	高度约8%	品牌、页面标题、一级导航、时间天气、全屏按钮
左侧监测栏	宽度约19%	运营概览、设备状态、环境监测、能耗监控
中央核心区域	宽度约61%	核心指标、厂区主场景、对象标签、图层工具栏
右侧运营栏	宽度约19%	风险分布、实时告警、隐患闭环、人员分析
底部监控区	位于中央区域底部	实时监控、事件处置流程、应急资源
模块间距	8～12px	建立清晰分区，避免内容拥挤
布局比例可以根据参考图进行像素级微调，不要机械套用比例导致视觉偏差。

十二、动效要求
动效整体保持克制。
允许使用：
HUD边框微弱呼吸发光；
中央标签轻微呼吸高亮；
面板淡入及小幅上移动画；
数据指标数字滚动动画；
图表平滑绘制动画；
数据卡片悬停时上浮2～4px；
悬停时边框发光略微增强；
告警点扩散波纹动画。
禁止使用：
夸张弹跳；
高频闪烁；
大幅位移；
过长的入场动画；
影响数据阅读的持续动画。
同时兼容 prefers-reduced-motion，用户关闭动效时应减少非必要动画。
十三、通用交互要求

全屏按钮控制浏览器进入和退出全屏；
所有可点击元素必须有明确的悬停和激活反馈；
弹窗、抽屉和详情面板均支持关闭；
页面中的模拟数据应集中管理，不要散落在组件内部；
数据结构应方便后续替换为真实接口；
不要使用大量不可维护的绝对像素定位；
中央标签允许使用基于画布的百分比定位；
所有列表、图表和指标不得为空；
模拟数据需要符合工业厂区业务逻辑。

浏览器控制台无报错；
