正泰集团厂区运营中心——访客定位管理专题页面需求说明
一、建设目标
在现有“正泰集团厂区运营中心”大屏基础上，建设独立的访客定位管理专题页面。
页面通过顶部“人员管理”导航进入，结合访客系统、门禁系统和UWB定位系统，集中展示访客实际入厂、实时位置、停留情况、移动轨迹和异常事件，实现访客从入厂、在厂活动到离厂的全过程可视化管理。
页面核心状态应以门禁通行、身份核验和UWB定位等系统自动采集的数据为准。预约信息和人工申报内容仅作为辅助信息，不作为判断访客实时状态的唯一依据。
二、页面入口与切换
点击顶部“人员管理”导航后，在当前大屏中切换到访客定位管理专题UI，不跳转至外部系统。
切换后：
顶部指标更新为访客管理相关数据；
左侧面板切换为访客统计和区域分析；
中央区域展示访客实时位置；
右侧展示访客异常事件；
其他专题的设备、能源、环境和监控标签不再显示；
页面整体框架和视觉风格与现有大屏保持一致。
从综合态势页面点击“访客实时管控”模块时，也应进入该页面，并默认筛选“当前在厂访客”。
三、页面结构
访客定位管理页面主要包括：
顶部访客核心指标；
左侧访客统计分析；
中央UWB实时位置展示；
访客分类和状态筛选；
右侧访客异常事件；
访客详情面板；
访客移动轨迹；
轨迹时间轴与动态回放。
四、顶部核心指标
顶部建议展示：
当前在厂访客；
今日实际入厂；
今日实际离厂；
定位在线率；
超时滞留人数；
当前异常人数。
指标判断原则：
当前在厂以实际入厂且尚未离厂的记录为准；
实际入厂和离厂时间以门禁通行记录为准；
定位在线状态以UWB标签心跳为准；
超时和异常状态由系统规则自动计算。
预约人数可以作为辅助信息，但必须明确标注为“预约”或“计划”数据，不能与实际人数混淆。
五、左侧访客统计分析
1. 访客实时状态
展示：
当前在厂；
正常活动；
即将超时；
超时滞留；
定位失联；
已离厂。
通过图表和数字结合的形式展示状态构成。
2. 访客区域分布
展示当前访客在各区域的分布情况，例如：
办公楼；
生产车间；
仓储区域；
动力站；
研发区域；
其他区域。
每个区域可展示：
当前访客人数；
正常人数；
异常人数；
人员密度或聚集状态。
点击区域后，中央视图定位并高亮对应区域。
3. 来访单位或来访类型统计
根据实际业务选择展示：
商务访问；
施工或检修；
物流配送；
项目交流；
参观访问；
其他来访类型。
该部分作为辅助分析，不作为判断访客实时状态的依据。
4. 停留时长分析
展示当前在厂访客的停留时长分布：
1小时以内；
1～2小时；
2～4小时；
4小时以上；
已超过计划时间。
重点突出长时间停留和超时访客。
六、中央UWB实时位置展示
1. 厂区总览
中央区域默认展示各厂区或建筑中的访客数量。
区域标签可包含：
区域名称；
当前访客数量；
异常访客数量；
当前区域状态。
例如：
1#生产车间
访客12人 · 异常1人
正常区域使用蓝色或紫色，存在关注事件时使用黄色，存在严重异常时使用红色。
2. 访客点位聚合
同一区域访客较多时，默认以聚合标签展示，避免人员图标相互遮挡。
点击聚合标签后：
展开该区域中的具体访客；
显示访客姓名或编号；
显示访客当前状态；
异常访客优先展示，不被普通访客隐藏。
点击空白区域或关闭操作后收起。
3. 访客实时点位
访客点位根据状态进行区分：
正常访客：紫色或蓝紫色；
即将超时：黄色；
超时滞留：橙色；
越界或限制区告警：红色；
定位失联：灰色。
悬停访客点位时可查看：
访客姓名；
所属单位；
当前区域；
实际入厂时间；
当前停留时长；
最后定位时间；
当前状态。
点击访客点位后，直接进入该访客的轨迹查看状态，并同步打开访客详情。
4. 区域详细定位
厂区总览主要展示区域级分布。
点击具体建筑或区域后，可以进入区域详细视图，优先使用客户UWB系统对应的平面图、楼层图或定位底图，展示访客实际坐标和移动轨迹。
如果演示阶段暂时没有UWB底图，可以使用合理的模拟坐标完成展示，但不应表现出超过实际能力的定位精度。
七、访客分类与状态筛选
访客范围筛选建议包括：
全部访客；
当前在厂；
今日入厂；
今日已离厂；
异常访客。
状态筛选建议包括：
正常；
即将超时；
超时滞留；
限制区告警；
定位失联。
支持根据厂区、建筑或楼层筛选访客。
筛选后，顶部指标、左侧统计、中央点位和右侧异常列表应保持一致。
八、访客详情
点击访客点位或异常事件后，在中央场景侧边或浮层中打开访客详情，避免完全遮挡定位视图。
1. 基本信息
展示：
访客姓名；
访客照片或头像；
所属单位；
被访部门；
被访人；
来访事由；
访客证编号；
UWB标签编号；
允许访问区域；
是否要求陪同。
2. 实际状态
展示：
当前所在区域；
实时位置；
实际入厂时间；
当前停留时长；
计划离厂时间；
最后定位时间；
门禁通行状态；
定位标签状态；
当前访客状态。
3. 数据来源区分
预约或人工申报产生的信息应标记为“申报信息”，例如：
所属单位；
来访事由；
被访人；
计划访问时间。
系统自动采集的信息应标记为“系统记录”，例如：
身份核验结果；
实际入厂时间；
门禁通行记录；
实时位置；
实际停留时长；
实际离厂时间；
异常事件。
两类数据应在页面中明确区分。
九、访客移动轨迹
移动轨迹是访客定位页面的核心功能。
1. 点击访客显示轨迹
用户点击访客点位后：
高亮当前访客；
弱化其他普通人员点位；
在中央定位区域绘制该访客的历史移动路线；
标记入厂点、当前位置、途经区域和异常位置；
同步打开访客详情面板；
显示轨迹对应的时间轴和区域记录。
默认展示该访客“入厂至今”的移动轨迹。
2. 轨迹时间范围
支持切换：
最近30分钟；
最近1小时；
最近2小时；
入厂至今；
自定义时间范围。
切换时间范围后，轨迹路线、停留节点、异常事件和时间轴同步更新。
3. 轨迹节点
轨迹中应区分：
入厂点；
普通途经点；
区域进入点；
区域离开点；
长时间停留点；
越界或其他异常点；
当前实时位置；
离厂点。
点击轨迹节点后，可查看：
所在区域；
到达时间；
离开时间；
停留时长；
当时的人员状态；
是否发生异常事件。
4. 定位中断
当UWB数据存在中断时，不应将中断前后的坐标直接连接成连续路线。
定位中断区间可采用：
虚线路径；
“定位中断”节点；
时间缺失提示。
避免向用户展示不真实的移动轨迹。
5. 跨区域和跨楼层轨迹
访客在不同建筑或区域之间移动时：
厂区总览展示跨区域移动关系；
进入具体建筑后，使用对应定位底图展示区域内部轨迹；
跨楼层时标记楼层切换节点；
时间轴中同步显示建筑和楼层变化。
十、轨迹动态回放
支持按照时间顺序回放访客移动过程。
回放流程：
点击访客
→ 选择时间范围
→ 点击播放
→ 访客点位按照时间顺序移动
→ 时间轴同步变化
→ 当前区域和事件信息同步更新
轨迹回放支持：
播放；
暂停；
调整播放进度；
调整回放速度；
重新播放；
退出轨迹模式。
播放到异常节点时，应突出显示异常位置和事件内容。
退出轨迹模式后，恢复全部访客点位和区域聚合状态。
十一、右侧访客异常事件
1. 异常类型
建议包括：
超时滞留；
进入未授权区域；
偏离规定活动区域；
与陪同人员距离异常；
定位标签失联；
访客证失效；
已登记离厂但定位仍在厂区；
长时间静止；
紧急求救；
异常人员聚集。
演示阶段可根据实际需求选择主要类型。
2. 状态筛选
异常列表顶部设置：
全部；
待确认；
处理中；
已处理。
每个标签显示对应事件数量。
3. 异常卡片
每条异常事件建议展示：
异常等级；
异常类型；
访客姓名；
所属单位；
当前区域；
发生时间；
当前处理状态。
点击异常事件后：
中央区域定位到对应访客；
自动展开访客所在区域；
高亮访客点位；
打开访客详情；
展示异常发生前后的移动轨迹；
时间轴自动定位到异常发生时间。
十二、访客列表
页面可通过详情入口或弹窗查看访客列表。
列表建议设置：
在厂访客；
待入厂访客；
已离厂访客；
异常访客。
列表字段建议包括：
访客姓名；
所属单位；
被访部门或被访人；
实际入厂时间；
当前区域；
停留时长；
定位状态；
当前状态。
点击列表中的访客后，同样在中央区域显示该访客的实时位置和移动轨迹。
十三、数据实时性
页面应显示数据更新时间和连接状态。
状态建议包括：
实时更新；
数据延迟；
定位服务中断；
门禁数据中断。
对于超过规定时间未更新的UWB标签，不应继续显示为正常在线，应标记为定位延迟或定位失联。
访客位置、停留时间、在厂状态、移动轨迹和异常事件应能够持续更新。
十四、轨迹数据要求
移动轨迹数据至少包括：
访客ID；
UWB标签编号；
定位时间；
X坐标；
Y坐标；
所属厂区；
所属建筑；
所属楼层；
所属区域；
定位状态；
位置事件类型。
位置事件类型可包括：
入厂；
区域进入；
区域离开；
普通移动；
长时间停留；
越界；
定位中断；
恢复定位；
离厂。
十五、隐私保护
大屏用于公共展示时，应避免直接展示完整敏感信息。
建议：
姓名根据使用场景部分脱敏；
不显示完整身份证号；
不显示完整手机号；
总览页面不展示详细证件信息；
访客照片和完整资料仅在有权限的详情页面显示；
活动轨迹根据权限控制查看范围。
十六、模拟数据要求
演示版本需要准备：
访客基本信息；
预约访问数据；
实际入厂和离厂时间；
UWB标签信息；
实时位置坐标；
区域进入和离开记录；
连续移动轨迹；
停留节点；
定位中断区间；
允许访问区域；
异常事件；
异常处理状态；
门禁和定位数据更新时间。
模拟轨迹应符合厂区道路、建筑和区域关系，避免路线穿越建筑、围墙或其他明显不合理的位置。
十七、主要交互流程
从综合态势进入
综合态势
→ 点击访客实时管控
→ 切换人员管理专题
→ 默认筛选当前在厂访客
→ 展示访客实时位置
查看访客轨迹
选择区域
→ 展开访客聚合点位
→ 点击访客
→ 高亮访客
→ 显示入厂至今的移动轨迹
→ 打开详情面板
轨迹回放
选择时间范围
→ 点击播放
→ 访客点位按时间移动
→ 时间轴同步变化
→ 查看停留点和异常节点
查看异常事件
点击异常事件
→ 定位对应访客
→ 打开访客详情
→ 显示异常发生前后的轨迹
→ 时间轴定位到异常时间
十八、验收要求
完成后的访客定位管理页面应满足：
可以通过顶部“人员管理”导航进入；
可以从综合态势的访客模块联动进入；
顶部指标切换为访客管理相关数据；
中央区域能够展示访客区域分布和实时位置；
人员密集区域支持聚合和展开；
支持访客状态和区域筛选；
点击访客后能够直接显示移动轨迹；
默认展示访客入厂至今的轨迹；
支持切换轨迹时间范围；
轨迹能够标记起点、当前位置、停留点和异常点；
支持轨迹动态回放；
定位数据中断时能够正确提示；
支持跨区域和跨楼层轨迹表达；
点击异常事件能够定位访客并展示对应轨迹；
申报信息与系统记录明确区分；
页面能够显示数据更新时间和连接状态；
敏感信息得到合理保护；
页面整体风格与现有大屏保持一致；
1920×1080分辨率下首屏完整显示；
页面无明显错位、遮挡、内容溢出或空白模块。
