- 集团层独立 Header、六项指标、左右 HUD 与底部协同态势已经接入

- 业主指定的 13 个全球制造基地已经进入配置化注册表：国内为佛山、嘉兴、南阳、咸阳、沈阳、合肥，国外为新加坡、马来西亚、柬埔寨、埃及、沙特、越南、印度尼西亚
- 当前国内点位采用城市中心附近临时坐标，海外仅给出国家的点位采用首都或代表性城市临时坐标，正式厂址经纬度待业主补充
- 分厂图钉悬停简介和数字模型接入状态已经接入
- 嘉兴基地支持下钻到现有二维园区大屏
- 园区层支持返回集团地球
- Three.js 已独立拆包并按需加载
- 嘉兴与其他重点基地之间的球面协同链路已经接入，动态效果改为线条材质高亮色带沿弧线流动，不再使用球形流动点
- 图钉密集区域动态避让和基地聚焦反馈已经接入
- 点击嘉兴后的地球聚焦、镜头拉近和下钻过渡已经接入
- WebGL 不可用时的二维基地入口兜底已经接入
- 左右 HUD、实时告警、协同动态和接入状态已经支持点击聚焦对应地球基地
- 合规 GeoJSON 加载器、资源注册表和审图号校验已经接入，正式边界资源仍待业务提供
- Natural Earth 5.1.1 China POV 国家边界已经作为开发预览层接入；生产构建默认不注册该资源
- 国家边界已经完成球面分段贴合，转到园区锚点视角时仍能稳定显示
- 地球已升级为清晰日间地表、夜间城市灯光与柔和昼夜分界，不叠加遮挡地理位置的厚云层
- 园区标注已升级为发光锚点、同心波纹、引导线和轻量信息标签，悬停时展示园区简介、主要产品与公开定位
- 园区地理锚点与标签避让已经解耦：锚点固定在真实经纬度投影位置，仅标签和引导线参与动态避让
- 密集区域的二维波纹与三维球面标记已经缩小，近距离园区标签按独立碰撞边界自动纵向分离
- 地球近景缩放范围已经扩展，支持继续拉近观察国家边界与园区密集区域，园区聚焦镜头同步增强
- 地表与夜间灯光已升级为 4096 × 2048 高清纹理，并根据 GPU 最大纹理尺寸自动回退 2048 × 1024 版本
- 园区常驻标签与悬停介绍框已提升字号；悬停框展示园区名称、所在地、公开介绍、主要产品和基地定位，不展示经营指标
- 集团主页已统一为全球制造数字展厅风格：左右使用渐隐式透明信息侧栏，降低完整边框和小卡片密度；地球保持全屏主视觉并略微放大，常驻基地城市信息弱化，经营增长采用一主三辅的公开指标层级

正式地图边界仍待取得合规授权资源。中国边界或行政区域不得直接使用来源不明的 GeoJSON；正式资源应以自然资源部标准地图服务系统的审图成果为依据，保留审图号与来源记录，再经过抽稀和球面坐标预处理后接入。

当前阶段保持集团页整体 HUD 布局不变，只完善地球与园区标注。下一步待集团页新版 UI 方案确认后，再统一调整信息层级与版式；正式发布前补齐合规地图边界、地球纹理授权和 1920 × 1080 视觉回归。

## 1. 目标与范围

在不改变现有 `1920 × 1080` 大屏画布、工业科技视觉体系和园区业务交互的前提下，将系统扩展为两级数字孪生入口：

```text
集团地球层
└─ 集团维度 HUD、指标、告警和制造基地汇总数据
└─ 可交互三维地球
└─ 制造基地发光锚点与园区简介
   ├─ 嘉兴正泰电气园区：点击进入
   └─ 其他园区：展示简介和数字模型建设状态

园区下钻层
└─ 园区维度 HUD、指标、告警和业务数据
└─ 嘉兴园区现阶段使用现有二维厂区图片
└─ 保留建筑、设备、人员、摄像头等现有图层与交互
└─ 支持返回集团地球层
```

集团层与园区层必须使用独立业务组件和独立数据源。允许复用 `HudPanel`、`BaseChart`、`ScreenFrame` 等无业务含义的基础视觉组件，但不得用嘉兴园区数据冒充集团汇总数据。

## 2. 固定技术路线

后续相关开发统一采用以下技术栈，不再引入平行的三维框架：

- 应用框架：Vue 3、TypeScript、Vite、Composition API、`<script setup lang="ts">`
- 三维引擎：原生 Three.js
- 地球交互：`WebGLRenderer`、`SphereGeometry`、`OrbitControls`
- 地图边界：GeoJSON 预处理后转换为贴合球面的 `BufferGeometry`
- 视觉效果：`Points`、`ShaderMaterial`、少量叠加式辉光
- 园区锚点与介绍卡片：Three.js 计算球面锚点，Vue DOM 负责展示和交互
- 状态管理：Pinia 隔离集团层、园区层与三维场景状态
- 页面下钻：Vue Router 4，使用 `/#/park/:parkId` 形式
- 园区模型：统一场景适配器支持 `image` 与 `gltf`
- 未来三维模型：GLB/GLTF，使用 Three.js `GLTFLoader` 按需加载

明确不采用：

- 不迁移 React
- 不在当前阶段引入 CesiumJS、Mapbox 或外部在线地图运行时
- 不使用 `ExtrudeGeometry` 直接生成球面地球
- 不把 HUD、文字卡片和复杂表格绘制进 WebGL Canvas

## 3. 架构设计

### 3.1 路由

| 路由 | 层级 | 内容 |
| --- | --- | --- |
| `/#/` | 集团 | 集团 HUD、三维地球、制造基地图钉 |
| `/#/park/jiaxing` | 园区 | 嘉兴园区 HUD、现有二维厂区场景 |
| `/#/work-order` | 移动作业端 | 保持现有工单处理流程 |

路由作为当前层级和当前园区的唯一页面级真值，支持浏览器前进、后退和园区地址直达。

### 3.2 数据

制造基地注册表至少包含：

```ts
interface ParkConfig {
  id: string
  name: string
  city: string
  longitude: number
  latitude: number
  status: 'connected' | 'building' | 'planned'
  sceneType: 'image' | 'gltf'
  sceneAsset?: string
  summary: string
  products: string
  positioning: string
}
```

集团数据与园区数据分别进入独立 store：

```text
groupStore
├─ 集团核心指标
├─ 制造基地注册表
├─ 跨园区告警
├─ 基地运行排名
└─ hoveredParkId

dashboardStore
├─ 当前园区主题
├─ 园区指标与点位
├─ 安全监控
├─ 访客管理
└─ 工单闭环
```

正式接口接入时建议保持以下边界：

```text
GET /api/group/overview
GET /api/parks
GET /api/parks/:parkId/overview
GET /api/parks/:parkId/alerts
```

## 4. 分阶段开发路径

### 第一阶段：双层架构与可运行闭环

- 新增集团层独立 Header、指标、左右 HUD 和底部协同态势
- 新增 Three.js 科技地球基础场景
- 建立制造基地配置和球面经纬度投影
- 实现悬浮锚点、悬停园区简介和背面锚点隐藏
- 嘉兴图钉点击进入 `/#/park/jiaxing`
- 嘉兴园区继续使用现有二维厂区图片与现有交互
- 增加“返回集团”入口
- Three.js 资源按页面生命周期初始化和释放

### 第二阶段：球面地图与视觉完善

- 接入经过授权与简化的 GeoJSON 世界、中国和省级边界；中国边界以带审图号的标准地图成果为依据
- 在资源目录保留原始来源、审图号、授权范围和预处理版本记录
- 通过统一资源注册表加载边界；未授权、缺少审图号或格式错误时保留基础地球，不阻断集团大屏
- 开发阶段可使用明确标记的 China POV 公共领域数据预览效果，但不得代替正式审图成果进入生产环境
- 中国区域重点高亮，补充经纬网、大气层和星空
- 使用本地昼夜纹理、引擎内置光照材质与大气辉光构建低云量、清晰地表和柔和昼夜分界
- 园区采用发光锚点、同心波纹、引导线和按需展开的信息标签
- 增加镜头聚焦、下钻过渡和空闲自动旋转
- 处理锚点密集区域避让和园区聚合
- 避让算法不得改变经纬度锚点的屏幕投影，只允许调整标签偏移和引导线
- 补充 WebGL 2 不可用时的二维地球兜底

### 第三阶段：集团业务数据完善

- 按集团口径确认制造基地清单、经纬度和介绍
- 确认集团指标定义、汇总算法和更新时间
- 接入集团接口或统一模拟数据服务
- 实现跨园区筛选、排行、告警联动和基地状态联动
- 高频数据按需要接入 WebSocket，统计数据使用轮询

### 第四阶段：嘉兴园区三维模型

- 获取并验收嘉兴园区 GLB/GLTF 模型
- 完成模型压缩、材质和纹理优化
- 将嘉兴配置从 `sceneType: image` 切换为 `sceneType: gltf`
- 将现有百分比点位映射为三维坐标或模型节点
- 完成建筑、设备、人员、摄像头与三维模型联动

### 第五阶段：多园区规模化接入

- 为每个园区增加配置、数据适配器和场景资源
- 按园区独立懒加载模型和业务模块
- 统一监控加载进度、错误兜底和 GPU 资源释放
- 建立园区模型资产规范、验收清单和版本管理

## 5. 性能与工程约束

- Three.js 仅在集团地球层或三维园区场景中加载
- 渲染像素比设置上限，避免高 DPI 大屏产生过高 GPU 压力
- 页面不可见或离开三维场景时暂停动画
- 场景卸载时释放几何体、材质、纹理、控制器和渲染器
- 地图边界在构建前简化，不在浏览器中处理超高精度原始数据
- 粒子使用单个 `Points` 或实例化结构，不为每个粒子创建独立 DOM/Mesh
- 第一阶段不使用重型后处理；辉光优先由 Shader 和叠加材质实现
- 生产资源本地托管或进入现有 OSS/EdgeOne 资源链路，不依赖失效外链

## 6. 验收标准

- 默认进入集团地球层，集团 HUD 不显示园区级数据
- 地球可旋转、缩放，动画和交互无明显卡顿
- 分厂发光锚点与经纬度位置一致，地球背面的锚点不显示
- 悬停锚点可以读取园区简介、状态和核心信息
- 只有已接入园区允许下钻，建设中园区给出明确状态
- 点击嘉兴进入园区层，现有二维厂区场景和业务功能保持可用
- 从嘉兴园区可以返回集团地球层
- 浏览器前进、后退与直接访问园区地址正常
- `1920 × 1080` 下无页面级溢出、主要内容无遮挡
- 构建、TypeScript 检查和 `git diff --check` 通过
- 不修改或移动稳定标签，不直接提交或推送 `main`
